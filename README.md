# Object-Oriented Programming — Laboratory Works

Репозиторий содержит лабораторные работы по дисциплине «Объектно-ориентированное программирование» (ООП).

## О проекте

Цель проекта — выполнение лабораторных работ по изучению принципов и инструментов объектно-ориентированного программирования на языке C++.

## Технологии

- **Язык программирования:** C++
- **Стандарт:** C++17
- **Компилятор:** MinGW-w64 (GCC)
- **Среда разработки:** Visual Studio Code
- **Дополнительные средства:** Windows API

## Сборка и запуск

Для сборки проекта с помощью MinGW-w64 откройте терминал в папке проекта и выполните:

```bash
g++ -std=c++17 -Wall -Wextra src/*.cpp -o matrix.exe
```

Запуск программы:

```bash
./matrix.exe
```

Для запуска с аргументами командной строки:

```bash
./matrix.exe 23 8 Y
```

## Структура веток

- `develop` — основная ветка для разработки лабораторных работ.
- `lab-01`, `lab-02`, `lab-03`, `lab-04` — ветки со стабильными версиями проверенных лабораторных работ.
- `about` — ветка с общим описанием проекта (`README.md`).

Новые лабораторные работы разрабатываются в `develop`. После проверки преподавателем соответствующая версия переносится в отдельную стабильную ветку.
